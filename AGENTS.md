# Fluid automation rule

Before creating, modifying, deploying, or retiring an agent, runtime skill,
cron job, recurring task, scheduled script, queue producer or consumer, or an
automatic Supabase process, read and follow
`hermes/automation-creator/SKILL.md`.

Do not implement recurring work before classifying and registering it. Hermes
is Fluid's only scheduler; host crontab and Supabase cron are not permitted.
